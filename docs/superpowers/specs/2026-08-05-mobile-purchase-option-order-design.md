# 手机端购买选项顺序与底部留白设计

## 目标

在 Store 购买选择页的手机布局中，将单品卡片显示在套餐卡片之前，并缩小最后一张卡片与页面底部之间的留白。

## 范围

- 仅修改 `src/views/shop/PurchaseOptions.vue` 的响应式布局。
- `768px` 及以下视口中，单品卡片在上，套餐卡片在下。
- 桌面端继续使用现有模板顺序和横向布局。
- 手机端移除页面额外外边距和最后一张卡片的下边距，页面底部保留至少 `24px`，同时兼容设备安全区。
- 不修改商品、套餐加载，会员权益过滤、选择或购买跳转逻辑。

## 验证

增加源代码契约测试，覆盖移动端顺序、末卡片间距和安全区规则；随后运行 Store 应用构建。
